An entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on [make.fun](https://make.fun).

`main.ts` writes a single-line joke about office life to `/output/entry.txt` — a "quick sync" Monday meeting where everyone is quietly updating their résumé. The program checks the joke against the competition gate itself (one line, 1–199 characters) before writing it.

Run it with Node 22 or later:

```sh
node main.ts
```
